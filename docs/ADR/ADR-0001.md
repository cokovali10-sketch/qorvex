# ADR-0001: Выбор языков и архитектуры

## Status

Accepted (Sprint 0)

## Context

Нужна масштабная open-source платформа (м потенциально >100k LOC) с компонентами:
- Orchestration / API
- Sandbox execution
- Static/dynamic analysis
- Web dashboard / MCP
- SQL storage

Требования: модульность, безопасность, тестируемость, наличие сообщества.

## Decision

- Go — основной runtime (API, orchestration, queue, store interfaces).
- Rust — sandbox / isolation layer (seccomp, namespaces, rlimits).
- Python — analyzers / ML integrations / automation.
- TypeScript — dashboard / MCP SDK / CLI helper.
- SQL (PostgreSQL) — persistent storage.

## Consequences

- Положительные: высокая производительность Go для I/O; Rust даёт нулевое накладное потребление на sandbox; богатая экосистема анализаторов на Python.
- Отрицательные: взаимодействие Go ↔ Rust требует FFI или RPC; Python runtime — медленный запуск; TypeScript — дополнительная сборка.

## Alternatives

- Только Go: сложно написать безопасный sandbox с низкоуровневым интерфейсом.
- Только Python: производительность, изоляция и многопоточность недостаточны.
- Kubernetes-native: избыточно для MVP, усложняет локальную разработку.
